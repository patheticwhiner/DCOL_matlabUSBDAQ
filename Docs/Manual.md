# USB_DAQ数据采集卡

## 1 采样基础知识

采样板卡把“过采样倍数（ad_os）”单独暴露出来，是因为采样链不只是单一的采样率参数——板卡内部还有模拟前端、ADC 时钟、**内部数字 sinc/抗混叠滤波器**和抽取（decimation）结构。单独设置 ad_os 能在硬件层面控制这些内部电路与**滤波→抽取**的组合，从而在带宽、噪声和数据速率之间做工程折衷，单靠“只改采样频率”无法覆盖这些实现约束与优化。

### 采样与Nyquist频率

连续信号 x(t) 的频谱 X(f) 在以 fs 采样后，会在频域被以 ±k·fs 周期复制（谱复制）。若原始信号在 f > fs/2 有能量，这些被复制的谱会与基带重叠并“折叠”到低频——即混叠（aliasing），这部分信息不可逆地丢失。因此，采样前必须保证带外能量足够小（模拟抗混叠），否则后续任何数字处理（包括插值）都无法恢复被混叠的成分。

在采样时，初学者可能只关心采样频率这一个变量。然而直接只改外部采样率而不改变内部滤波/抽取，会导致高频能量被折叠（混叠）。板卡通过 ad_os 明确告诉你“我在内部做了多少倍过采样并用哪种滤波器去掉镜像/带外”，从而保证输出带宽和频谱形状。

### 模拟抗混叠滤波器

模拟抗混叠滤波器的作用是在进入ADC之前把高于 fs/2 的模拟能量衰减到很低水平，避免混叠。由于这些模拟滤波器是固定的，因此需要用户按要求，从有限的选择中选取。

需要说明的是，垂直滚降的理想模拟滤波器是不可实现的，实际的滤波器有过渡带和相位/群延迟，为此必须引入ADC内部过采样，用数字域滤波代替严格的模拟滤波。模拟滤波器的截止频率低于ADC的Nyquist并能对极强的带外干扰提供足够的衰减，而这些衰减不足的部分，则由数字域滤波提供严格的带外抑制。

### 过采样的权衡

引入过采样的原理是，在 ADC 端以高于最终输出率的内部速率采样（内部采样率 = 外部 Rate_Sample × ad_os），**板卡在数字域用滤波器（通常是 sinc/多级 FIR）去掉带外，然后做抽取（decimation）到目标输出率**。通过过采样来弥补模拟抗混叠滤波器的不足，有时也被称作”用数字滤波代替严格的模拟滤波“。

- **板卡内部数字滤波与抽取**：ad_os 对应不同的内部 decimation/数字滤波器配置（例如不同长度/截止的 sinc 型滤波器），从而决定可接受的最大外部 Rate_Sample 与 3dB 带宽。表格里列出的 Rate_Sample/3dB 带宽正是这些内部滤波+抽取设计允许的组合。
- **资源、延迟与数据率权衡**：同时，更高的过采样意味着更高的瞬时数据率（以及更大内部滤波计算/延迟），但之后的抽取能把数据率降回目标值。软件中暴露 ad_os 方便用户在**“模拟滤波难以做陡峭”** vs **“可接受更高处理开销/延迟”**之间做选择。

### 量化噪声：为何过采样能降低基带噪声

量化步长 Δ，均匀量化近似下总噪声功率 ~ Δ^2 / 12（整个 Nyquist 带宽内）。

如果采样率提升到 L·fs，噪声仍然在更宽的频带（宽度约 L 倍）上均匀分布；基带（原 fs/2）所占噪声份额变为 1/L，因此带内噪声功率下降 1/L，SNR 提升约 10·log10(L) dB。

**SNR / 量化噪声收益**：过采样把量化噪声扩散到更宽频带，基带内噪声功率会下降（不带噪声整形时，过采样倍数 L 带来约 10·log10(L) dB 的带内噪声功率下降），因此可以提升有效分辨率或降低系统噪声。数学表达：
$$
ΔSNR_{dB}=10\log_{10}L
$$
例如每倍数为 2 时约 +3.01 dB 的带内噪声降低。

注意：这是在无噪声整形的条件下；ΣΔ 等结构可进一步把噪声向高频推，基带获益更大。

### 为什么不能“只配置采样频率”

综上，“采样率”只是外部接口速率的一部分，板卡内部可能固定以某一高速时钟工作，采样率与内部滤波/decimation 的组合才决定最终有用带宽与输出数据流。用户若只改外部 Rate_Sample 而不改 ad_os，可能会违背内部滤波规格或导致混叠/带宽超出限制。

表格把 ad_os 映射到“对应过采样倍数、Rate_Sample 最大值、3dB 带宽”——这是典型的硬件设计约束与预设滤波器组的结果，用户选择 ad_os 实际上是在选择预定义的硬件/固件滤波器和抽取比。

### 工程建议（如何选）

- 目标是带限采样且尽量低混叠：优先保证模拟端在 fs/2 处有足够衰减；若模拟滤波器受限，选择较高的 ad_os（过采样）并在数字域做低通再抽取。
- 需要更高 SNR：增加过采样倍数（L），注意带内噪声下降约 10log10*L* dB，但同时关注数据处理能力与延迟。
- 实测验证：用窄带/扫频信号或噪声做 FFT 检查抽取后基带有没有混入高频镜像（笔记里的频谱绘制函数可参考 `plot_time_and_spectrum`与 `plot_three_spectra` 示例）。

## 2 AD操作函数

采集卡可以单次同步采集所有通道并返回，也可以以通道连续同步采样，数据同时上传到计算机内存，由应用程序读取内存中的数据。用于采集的AD操作函数主要包括`ad_single()`，`ad_continu_conf()`，`ad_continu()`，`ad_continue_stop()`和`read_adbuf()`及`get_adbuf_size()`等。

AD启动转换时钟可以软件选择为由板上时钟或外部时钟控制，具体参考函数说明，外部转换时钟的周期或速度要求同板上定时器。<u>如果在AD 转换结束前，有外部时钟触发，将丢掉这个有效触发时钟</u>。返回的数据会根据所选择的量程自动计算为**AD 通道输入的实际电压值**，返回数据类型为**单精度浮点型**。

采集卡的启动或触发控制分为两种：软件启动/外部硬件触发，具体参考函数说明。

### 2.1 单次瞬时采样 ad_single()

作用是快速捕获采集通道的当前电压值（不需要连续存储）。典型的应用场景包括：设备上电自检（检查传感器供电是否正常）和手动触发式测量（只有按下按钮时读取一次温度值）。

```MATLAB
loadlibrary('Usb_Daq_V52_Dll','Usb_Daq_V52_Dll.h');     % 加载动态链接库，其中第一个为动态链接库的名字，第二个为头文件
x = calllib('Usb_Daq_V52_Dll','openUSB');    			% 调用动态链接库内部的函数，openUSB(void)无参数输入
% 单词瞬时采样
a = single(1.0:8.0);    								% 初始化一个8元素的一维数组
pv = libpointer('singlePtr', a);    					% 用libpointer函数来构造指针 
x = calllib('Usb_Daq_V52_Dll','ad_single',0,1,pv);    	% AD_single(int ad_os,int ad_range,float* adResult);
ADsigle = get(pv, 'Value');    							% 指针值复制到另一个数组用于显示 
```

### 2.2 高速连续采样 ad_continu_conf()

##### 函数设置与硬件交互流程

1. **初始化**：PC端调用`openUSB()`，FPGA复位各模块。
2. **用户调用函数**（如`ad_continu_conf()`）设置参数（包括`freq`）。
3. **驱动通过USB传输配置命令**到FPGA。
4. **FPGA更新分频器寄存器**，调整时钟分频比。
5. **硬件定时器按新频率输出时钟**，触发AD转换。
   - FPGA按配置采集数据→存入FIFO→USB批量传输至PC缓冲区。
   - PC周期调用`Read_AdBuf()`读取数据，直至`AD_continu_stop()`终止。
6. **关闭设备**：PC端调用`closeUSB()`
7. **限制与注意事项**：ProASIC3为固定逻辑架构，功能需预先烧写，不支持动态重配置（如更换PWM分辨率）。

##### 如何设置？

+ **采样频率设置**：文档明确提供了用于配置采样频率的函数接口（如`ad_continu_conf()`），用户可通过参数`freq`指定采样率（单位：Hz）。`freq`参数直接控制AD转换的时钟频率，支持范围受硬件限制（最高100kHz）。采集卡提供两种时钟源，通过函数参数`clk_sl`选择
  + **使用内部时钟**（`clk_sl = 0`）：FPGA内部采用**48MHz基准时钟**，通过**分频器**生成所需采样时钟。内部时钟是由FPGA内部的定时器生成时钟信号，频率由`freq`参数计算得出。
    + 过采样模式：过采样模式会进一步降低有效采样率（如64倍过采样时，最大采样率为3.125kHz）。
  + **使用外部时钟**（`clk_sl = 1`）：使用外部输入信号（通过DI1引脚）作为时钟源，此时`freq`参数无效，采样率由外部信号频率决定。外部时钟通过DI1引脚输入，支持上升沿或下降沿触发（由参数`ext_clk_pol`控制），外部时钟的频率不应大于100kHz。

### 2.3 简化连续采集 ad_continu()

```matlab
loadlibrary('Usb_Daq_V52_Dll','Usb_Daq_V52_Dll.h');     % 加载动态链接库，其中第一个为动态链接库的名字，第二个为头文件
x = calllib('Usb_Daq_V52_Dll','openUSB');    			% 调用动态链接库内部的函数，openUSB(void)无参数输入
% 以10K的采样速率连续采集1024个点，增益为0，过采样0
NumSamp = 8*1000;    					% 数据个数必须是8的整数倍，一共8通道，每通道采样1000个数
FrqSamp = 20000;    					% 采样频率设为10KHz
b = single(zeros(8,1000));    			% 初始化一个8X1000的数组用于保存数据
pv = libpointer('singlePtr', b);    	% 用libpointer函数来构造指针 
x = calllib('Usb_Daq_V52_Dll','ad_continu',0,0,FrqSamp,0,0,0,0,NumSamp,pv);    
NumBuf = get(pv, 'Value');    			% 将指针数据复制到一个数组内
```

### 2.4 缓冲区读取 get_adbuf_size() read_adbuf()

使用 `get_adbuf_size` 轮询缓冲区的数据点总数，直到数据长度达到我们需要的数值后再集中读取。`read_adbuf` 将缓冲区的数据传到电脑内存里（人为指定需要读取的点数，并返回实际读到的点数）。
